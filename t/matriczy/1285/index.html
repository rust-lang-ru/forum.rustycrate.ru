Функция pow() Тех.вопросы
2_i32 это целочисленный литерал типа i32 со значением 2: “_” это разделитель, который можно вставлять в любое место числа (тут он использован, что бы визуально отделить значение от суффикса) “i32” это опциональный суффикс, явно обозначающий тип (тут он неоходим, потому что pow метод реализован для конкретных типов и без него была бы ошибка E0689) https://doc.rust-lang.org/reference/tokens.html#integer-literals

Если одной и той же константой, то смотри выше.

Если надо проитерироваться по каждой клетке, то, например, так:

fn main() {
    let mut m = [[10_i32; 3]; 3];
    for (i, row) in m.iter_mut().enumerate() {
        for (j, cell) in row.iter_mut().enumerate() {
            *cell = (i * 10 + j) as i32;
        }
    }
    dbg!(m);
}
вывод 
[src/main.rs:8] m = [
    [
        0,
        1,
        2,
    ],
    [
        10,
        11,
        12,
    ],
    [
        20,
        21,
        22,
    ],
]
