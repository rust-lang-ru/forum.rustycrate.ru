https://forge.rust-lang.org/

Сайт с полезной информацией для участников Проекта Rust.
Для простых пользователей тоже есть много полезного и интересного:

  • даты будущих релизов;
  • состояние сборки внешних инструментов из основной ветки Rust и архиполезная ссылка на таблицу состояния компонентов ночных сборок;
  • таблица состояния нестабильных фичей (unstable features) Rust;
  • список поддерживаемых платформ;
  • библиография Rust - список материалов на основе которых формировалась система типов, владения и заимствования в языке.

К сожалению не все страницы сайта содержат актуальную информацию. Например, история релизов заканчивается на версии 1.7.0.

P.S.: Некоторые ограничения на минимальное количество символов бесят. Зачем нужно 15 символов в названии темы?
